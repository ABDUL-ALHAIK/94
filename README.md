Preview: open index.html in any modern browser.

Free publishing (GitHub Pages):
1. Create a free GitHub account.
2. Create a public repository, e.g. abdulrahman-portfolio.
3. Upload index.html to the repository root (photo is embedded).
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Your public URL will appear after deployment.

Alternative: drag the whole folder to Netlify Drop (app.netlify.com/drop).

Languages: English / Arabic (RTL) / Portuguese (Brazil) — switch in the top bar.
Payments: PayPal, Bitcoin, USDT, Pix are listed; account details are shared privately on request.

Credentials section: 12 course certificates + the technical diploma (text only).
All images are embedded inside index.html, so uploading index.html alone is enough.
Privacy: CPF numbers were hidden on the certificates that showed them. The diploma and
the course-completion statement contain ID/CPF/birth date and are NOT published.

PAYMENTS (QR): open index.html in a text editor and search for "EDIT YOUR PAYMENT DETAILS HERE".
Fill paypal / payoneer / wise (links), pix (key), bitcoin and usdt (address + network). Save and re-upload.
Any method left empty shows "details shared after the project is confirmed" + a WhatsApp button instead of a QR.

GALLERIES: Cases and Certificates are auto-sliding carousels (2 s hold per step, left-to-right).
They pause on mouse hover, while an image is open, and with the Pause button. Visitors who have
"reduce motion" enabled see a normal static grid instead.
